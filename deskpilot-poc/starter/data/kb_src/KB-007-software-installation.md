# Software Installation Requests

Document ID: KB-007 | Owner: Fabrikam IT Help Desk | Last reviewed: 2026-09-01

## Approved software

Approved applications are listed in Software Center on your laptop. You can install them yourself at any time. Examples include the Microsoft 365 apps, Visual Studio Code, Python, and Zoom.

## Software that is not in Software Center

1. Raise a ticket in category Software and name the product, the version, and the business reason.
2. Your manager must approve the request.
3. IT Security reviews the product. This takes up to 3 business days.
4. If approved, IT deploys the software to your laptop.

## Rules

Standard users do not have local administrator rights. Paid software needs a cost center code from your manager. Personal licenses are not allowed on company laptops.

## If the steps fail

Raise a ticket in category Software. Use priority Low. Response targets: Critical 1 hour, High 4 hours, Medium 1 business day, Low 3 business days.
