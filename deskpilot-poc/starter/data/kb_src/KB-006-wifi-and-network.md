# Wi-Fi and Office Network

Document ID: KB-006 | Owner: Fabrikam IT Help Desk | Last reviewed: 2026-09-01

## Networks

Fabrikam-Corp is the employee network. It uses a device certificate, so no password is needed. Fabrikam-Guest is for visitors. Reception issues a daily code that is valid for 8 hours. Never connect company laptops to Fabrikam-Guest.

## Common problems and fixes

1. The laptop cannot join Fabrikam-Corp. Select Forget this network, restart the Wi-Fi adapter, and join again.
2. The certificate expired. Device certificates renew every year. Open Company Portal and choose Sync to renew it.
3. Slow Wi-Fi. Move closer to an access point and prefer the 5 GHz band.
4. Wired network port is dead. Try another port, then raise a ticket with the port label from the wall plate.

## If the steps fail

Raise a ticket in category WiFi. Use priority Medium. Use priority High if a whole team is affected. Response targets: Critical 1 hour, High 4 hours, Medium 1 business day, Low 3 business days.
