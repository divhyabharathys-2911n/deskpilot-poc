# Multi-Factor Authentication (MFA) Setup and Recovery

Document ID: KB-003 | Owner: Fabrikam IT Help Desk | Last reviewed: 2026-09-01

## Overview

Every Fabrikam account requires multi-factor authentication. Fabrikam uses the Fabrikam Authenticator app. Sign-in prompts use number matching: you type the number shown on the sign-in screen into the app.

## Set up MFA on a new phone

1. Install Fabrikam Authenticator from your phone's app store.
2. Go to https://mysignins.fabrikam.example and choose Add sign-in method.
3. Scan the QR code with the app.
4. Approve the test prompt.

## Changing phones

Move your account to the new phone before you reset the old one. In the old app, choose Transfer accounts and follow the steps on the new phone.

## Backup codes

Each user can create 10 single-use backup codes at https://mysignins.fabrikam.example. Store them in a safe place. Each code works once.

## Lost or stolen phone

Raise a ticket right away. The help desk can issue a Temporary Access Pass that is valid for 8 hours so you can register a new phone. Your manager must confirm the request.

## If the steps fail

Raise a ticket in category MFA. For a lost phone use priority High. Response targets: Critical 1 hour, High 4 hours, Medium 1 business day, Low 3 business days.
